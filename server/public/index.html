    Auth & headers

    Sent with every request to this API. Use Authorization: Bearer … for tokens. After a login request, Use token on the response fills this in for you. Cookies the API sets are kept automatically.

    Paste cURL

    Paste a curl command, e.g. from the browser's DevTools (right-click a request › Copy › Copy as cURL, bash or cmd). It opens as a request you can send and then save to Custom.
